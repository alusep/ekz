# ДЭ 2026 — Приложение авторизации

Демонстрационный экзамен, КОД 09.02.07, Модуль 5.

## Функциональное назначение

Приложение реализует форму входа в систему с проверкой логина и пароля,
интерактивной капчей и разграничением прав по ролям.

Возможности:
- вход по логину и паролю;
- капча «собери картинку из фрагментов»;
- блокировка пользователя после 3 неудачных попыток входа;
- роли: администратор и пользователь;
- панель администратора: просмотр, добавление, блокировка пользователей;
- валидация ФИО клиента из API TransferSimulator на запрещённые символы.

Технологии: Python 3, Tkinter, FastAPI, Uvicorn.

Реализованы две версии интерфейса:
- настольная (Tkinter) — основная;
- веб-версия (FastAPI) — дополнительная.

## Используемые методы

### Модуль auth.py

**hash(password: str) -> str** — возвращает SHA-256 хеш пароля.

**login(username: str, password: str) -> tuple** — проверяет логин и пароль.
При успехе возвращает объект User и None. При ошибке — None и код ошибки
(not_found, invalid, blocked). При 3 неудачных попытках блокирует пользователя.

**make_token(user: User) -> str** — создаёт токен сессии для пользователя.

**current(token: str) -> User | None** — возвращает пользователя по токену.

**add_user(name: str, pwd: str, role: str) -> tuple** — добавляет нового
пользователя. Проверяет, что логин не занят.

**set_blocked(name: str, blocked: bool) -> tuple** — блокирует или
разблокирует пользователя.

### Модуль captcha.py

**new_captcha() -> dict** — создаёт капчу. Возвращает id сессии и
перемешанный порядок фрагментов.

**check_captcha(sid: str, order: list[str]) -> bool** — проверяет,
правильно ли пользователь собрал картинку.

### Модуль transfer_sim.py

**get_full_name() -> str** — запрашивает ФИО клиента у API
TransferSimulator. Если сервер не ответил, возвращает пример из ТЗ.

**validate_full_name(name: str) -> tuple** — проверяет ФИО на
запрещённые символы (цифры, @, &, %, !). Возвращает (True/False, сообщение).

### Модуль gui.py

**LoginWindow** — окно входа: поля логин/пароль, капча из 4 картинок,
кнопки «Обновить капчу» и «Войти».

**LoginWindow._click(i)** — обработка клика по фрагменту капчи
(выделение и обмен местами).

**LoginWindow._login()** — проверка капчи и логина/пароля, вывод сообщений.

**AdminWindow** — окно администратора: список пользователей,
добавление, блокировка и разблокировка.

### Модуль validator.py

**run()** — открывает окно валидации ФИО с кнопками
«Получить данные» и «Отправить результат теста».

### Модуль main.py

**GET /api/captcha/new** — выдать новую капчу.

**POST /api/auth/login** — вход. Параметры: username, password, sid, order.
Возвращает ok, message, token, role.

**GET /api/admin/users?token=...** — список пользователей (только для админа).

**POST /api/admin/add?token=...** — добавить пользователя (только для админа).

**POST /api/admin/block?token=...** — заблокировать/разблокировать пользователя.

## Сообщения системы

- неверные данные: «Вы ввели неверный логин или пароль. Пожалуйста проверьте ещё раз введенные данные»
- успешный вход: «Вы успешно авторизовались»
- блокировка: «Вы заблокированы. Обратитесь к администратору»
- занятый логин: «Пользователь уже существует»
- капча не пройдена: «Капча не пройдена»
- ФИО с запрещёнными символами: «ФИО содержит запрещенные символы»

## Запуск

### Настольная версия (Tkinter)

    .\.venv\Scripts\Activate.ps1
    python -m app.gui

### Окно валидации ФИО

    python -m app.validator

## Запуск

Перед запуском открой терминал в папке проекта и активируй окружение:

    cd "C:\Users\User\Desktop\2026 ДЭ\ekz"
    .\.venv\Scripts\Activate.ps1


### Веб-версия API с авторизацией (FastAPI)

    uvicorn app.main:app --reload

После запуска открой в браузере: http://127.0.0.1:8000


### Тестовые учётные записи

Для входа в любую из версий используй:

- admin / admin123 — администратор
- user / user123 — пользователь

| Нажать «Получить данные» | ФИО отображается на форме |
